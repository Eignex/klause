# klause-bench

JVM benchmark catalog, corpus management, subprocess runner and measurement tools.

See [benchmarking](../docs/benchmarking.md), [LP capture and replay](../docs/lp/replay.md),
[diagnostic tools](../docs/testing/tools.md) and [fixture provenance](../docs/testing/fixtures.md).

Rebuild the CLI with `:klause-cli:installJvmDist` before measuring Klause, or use
`:klause-bench:solveCampaign`, which builds it and selects the JDK automatically.
