# Partial numeric conflicts

These self-authored Apache-2.0 fixtures exercise exact sign conflicts before a
Boolean region is complete and reuse under unrelated Boolean prefixes. The
manifest pins version 1 membership, source hashes and expected source verdicts.

The early layout puts the numeric guard before independent Boolean pairs; the late
layout puts it after them in declarations and formula traversal. Each has one,
two or four independent pairs. This controls the explanation obligation without
changing the solver's decision policy. The SAT guard can be true with zero real
coordinates. In each UNSAT branch, two equally signed nonzero coordinates are
required to have a negative product, which is impossible. All 33 real declarations
remain source identities; unused declarations keep the complete assignment check
and separate these controls from the small-query optional witness producer.

Prepared-service and ordinary CLI observations have different scopes: CP pins or
source preparation can settle a guard before the region enumerator sees it.
Retain actual query dimensions, learned premises and source-checker receipts when
interpreting a run. The fixtures provide no independent UNSAT certificate.
